## 查看器裁切调查与尺寸防护

用户报告从工程管理/我的返回后，画布或模型只显示一部分。本轮使用真实 SDK 与 4096 点球形 PLY，在 HA28L0L4 上检查切页、隐藏时转屏和全屏返回，尚未稳定复现原始裁切。**不能声称已经确认该报告的根因或覆盖所有触发条件。**

代码检查确认两个尺寸同步边界：初始绑定可发生于 0×0 尺寸；已绑定 generation 的重复 attach 会跳过尺寸同步。新增 JVM 测试先失败，再修复：等待正尺寸，保留同一 generation 时也更新视口。Android 绑定统一读取 holder 的实际缓冲区尺寸，surfaceChanged 使用其回调尺寸，且遵守可见性与销毁保护。没有重建 Viewer 或重新适配相机来掩盖问题。

新设备恢复测试保留一个 Native3dgsView，工程/账号等分支为隔离 Scaffold；每次返回要求收到更大的原生 surfaceGeneration 的 Ready，避免误用切页前保留的 Ready。该测试验证真实 SDK 生命周期，**不是后端/账号 E2E 或像素完整性证明**。
