# Android 模型库与按需画布验证，2026-10-20

本记录补充 [前一轮 UI 验证](mobile-ui-2026-10-20.md)。前一轮加载球形模型的切页验证没有覆盖空 Surface 残留，本轮以用户保留的现场和新交互要求为范围。仅修改 apps/android。

## 现场与实现

读设备屏幕确认：从“我的”切换到查看器，Viewer 标题/工具出现，原生空 Surface 区域仍保留账号页面。本轮消除该空画布路径：首次打开前不创建 Native View；下载/选文件时保留浅色模型库，获得文件后显示预览；首帧前完整不透明加载层遮住原生区域。已创建的 View 保持单实例，关闭后隐藏，避免反复销毁引擎。

Pad 左侧为真实工程模型列表，右侧为本机入口；Phone 列表右上侧保留本机图标。工程选择只用于浏览，不修改当前工作工程，不新增全站模型 API。预览与全屏都能呼出云模型菜单、打开本机文件、退出全屏及关闭。相机工具改为 48dp 图标，保留 tooltip、语义和按住自由移动行为。

沿用 apple-design 与 design-taste 的 Operate 模式，设计/动效/密度为 4/4/5：品牌蓝、系统字体、分隔列表、触点弹簧反馈，键盘与减少动画保持静止；工具 Sheet 220ms 进入/180ms 退出，减少动画时立即切换。原生画布祖先不使用透明度/缩放动画、裁剪或模糊。

| Before | After | Why |
|---|---|---|
| 空场景立即创建原生幕布 | 按需画布与不透明模型库 | 消除未呈现空帧暴露旧页面的路径 |
| 常驻说明与文字操作占据预览 | 紧凑图标栏、按需状态提示 | 给模型更多空间，保留功能语义 |
| 紧凑布局本机入口占单独大块 | 云列表右上侧图标 | 短屏与 200% 字号下保留列表空间 |
| 模型库顶部状态固定不可滚动 | 工程、错误和行共同滚动 | 短窗口仍能访问数据与重试 |
| Filled tonal 使用默认高饱和次色 | 品牌蓝次色与柔和背景 | 避免不一致的鲜绿色入口 |
