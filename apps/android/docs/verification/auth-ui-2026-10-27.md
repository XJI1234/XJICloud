## 设备用户路径

1. 启动页显示精简认证说明和“隐私权政策”链接，未勾选同意；无独立阿里云说明标题或裸 URL。
2. 点击政策打开应用内正文，显示运营主体、隐私邮箱、更新/生效日期与信息处理章节，可滚动阅读；返回不会自动勾选同意。正文随包内嵌，无网络加载依赖。
3. 主动勾选后发起一键认证，无 SIM 设备转入短信注册，红色提示精确为“未识别到本机号码”，图形码与输入框同排。
4. 点击手机号字段并分段输入测试号码；图形码保持不变。对输入前后截图的验证码区域逐像素比较，差异为空；Widget 测试另断言同一图片 provider 和无额外验证码请求。设备当前输入法表现为浮动输入工具栏，完整键盘遮挡由 Widget 模拟覆盖。
5. 桌面应用名称显示“玄境云”。图标以用户指定的 web2 `logo_nw.png` 生成密度资源与 Android 自适应前景，原图未修改。

## UI 复核

| Before | After | Why |
| --- | --- | --- |
| 长说明、阿里云说明标题与裸 URL 占据登录页 | 精简用途说明，协议文字为本地“隐私权政策”入口 | 保持主要操作清晰，政策可离线阅读 |
| 图片单独一行且输入时重新解码 | 输入框与图片同排，同一 challenge 复用图片数据 | 稳定排布，避免输入与键盘重建闪烁 |
| 未识别号码时展示冗长解释或先遇到后端初始化错误 | 确定无 SIM 后直接回退并显示简短原因 | 用户立即获得可用的下一步 |
| 手机号冲突落为通用“操作失败” | 已知冲突显示“该手机号已注册，请使用密码登录。” | 给出真实原因和操作方向 |
