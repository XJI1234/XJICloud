## 部署协议预验收

本节是 API 路径验证，不是产品 UI E2E。

- 模型：创建会话、半段上传、GET 恢复位置、已写范围重放、尾块均成功。首次 complete 成功，但返回 ID 与列表实际 ID 不同；重复 complete 404。用列表实际 ID 下载，SHA-256 与 279000-byte 原件完全一致。客户端处理要求见 API_REUSE。
- 数据集：本轮独有工程上传四张 JPEG 及一次 manifest，OSS 使用 HTTPS 且未携带用户 Bearer；complete 后为 QUEUED。尚未观察 Worker 领取、训练完成或产物下载。
