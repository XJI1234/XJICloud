## SDK 固定依赖与打包

- 来源、ZIP/AAR SHA-256 与 manifest 清单校验沿用 [原生接入规格](../NATIVE3DGS.md)。脚本先校验完整发布包，再保存 AAR、manifest、文档与许可证；不重复打包 ZIP 中独立 lib 副本。
- 本轮使用 NDK llvm-readelf 检查 AAR 内 ELF：libc++_shared.so 的 LOAD align=0x4000；libgs_android_decoder.so 的 LOAD align=0x1000。
- **SDK 0.2.2 的解码库未满足 16KB ELF 对齐。** APK zipalign 成功也不能修复该问题；发布到 16KB 页环境需要上游兼容 SDK 与重新验收，本轮不重建或修改固定 SDK 二进制。
- APK ZIP 无重复条目，仅 arm64-v8a；libc++_shared.so 与 libgs_android_decoder.so 各一份。合并 Manifest 确认 DecoderService exported=false、process=:native3dgs_decoder；私有 FileProvider exported=false，路径仅开放受控输入副本目录。
