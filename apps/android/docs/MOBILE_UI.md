# Phone / Pad UI 与交互规格

2026-10-19，供评审和后续 Widget 验收使用，不代表页面已实现。

## 1. 视觉系统

直接对齐 `apps/web2/src/presentation/styles/shell.css` 的现有主题，不照搬桌面侧栏。Flutter 用自定义 `ThemeExtension` 承载精确 token，不能只设置 Material seed 后接受自动生成的偏色。

| Token | 值/约定 |
|---|---|
| 产品背景 / 卡片 / 登录背景 | `#f5f6f8` / `#ffffff` / `#ffffff` |
| 主字 / 次字 / 弱字 | `#1c1f24` / `#5c6370` / `#8b919c`；弱字仅辅助，不作关键字段 |
| Accent / Pressed | `#3d6b8a` / `#345c76` |
| Accent soft | `#3d6b8a`，12% alpha |
| 错误 / 成功 | `#b42318` / `#2f6f4e`；状态还需文字/图标 |
| 分隔线 / 强边线 | `#1c1f24`，8% / 14% alpha |
| 圆角 | 输入/控件 10dp，卡片/Sheet 16dp，胶囊 999dp |
| 空间 | 基础 4dp，常用 8/12/16/24/32；Phone 边距 20，Pad 32 |
| 字体 | 系统字体；标题 24/28sp、分组 18sp、正文 16sp、辅助 14sp |
| 触控 | 最小热区 48×48dp；正文随系统字级缩放 |
| 按钮 | Primary / Ghost / Destructive；同屏主任务突出一个主按钮 |
| 画布 | 暗背景，不把所有产品界面切为暗色 |

动效：按下 0.97，100ms；表单/Sheet 160–220ms；页面淡入/轻位移 180–240ms。无大弹跳，减少动画模式关闭非必要位移和循环动画；加载提供静态文字而非只靠动画。

## 2. 响应式规则

按窗口可用逻辑宽度分档，用 `LayoutBuilder`，不通过型号/横竖屏猜布局。

| 可用宽度 | 布局 |
|---|---|
| `<600dp` | Phone 单列，详情入二级页，表单底部 Sheet 或全页 |
| `600–839dp` | Pad 窄窗；卡片可两列，详情仍单页；登录表单限宽 420dp |
| `>=840dp` | Pad 宽窗；工程列表约 300dp + 24dp 间隔 + 自适应详情；内容限宽 1280dp |

分栏指**列表与详情**，不提供双模型/双画布。系统分屏缩到 600dp 以下后自动回单列，已选工程/表单/上传事务保留；只保留一个 Viewer 实例，不因布局重建重复加载模型。

Phone 验收窗口：360×800、390×844、横屏 800×360；Pad：800×1280、1280×800；另测 599/600/839/840dp 边界、200% 字号、软键盘、安全区域与系统分屏。底栏有 SafeArea，键盘打开时不挤出表单提交按钮。

## 3. 导航与上传入口

```text
┌──────────────────────────────────────┐
│ 页面标题              当前工程/菜单  │
│                                      │
│       当前页面内容（独立滚动）        │
│                                      │
├───────────────    ────────────────────┤
│ 主页   工程    (↑)    模型查看   我的  │
└──────────────────────────────────────┘
```

底栏从左到右严格为主页、工程管理、模型查看、我的；中央为 56–64dp 圆形上传主按钮，抬高约 10–12dp，周围留空，四个目的地均显示图标与文字。Pad 同样保留底栏，以用户指定布局为准。200% 字号时底栏允许增高/两行标签，不裁切名称。

上传是全局动作，不是第五个持久 Tab。点击弹出“上传图片并训练 / 上传 PLY/SPZ 模型”，随后进入分步页面；无当前工程先选/建工程，再选文件。任务开始后 Header 展示固定的目标工程，避免切工程误归属。返回保留所来源的 Tab；上传页切换目的地前说明传输/草稿状态。

四个 Tab 用有状态路由分支保留滚动/选择，Viewer 在隐藏时解除 Surface/暂停渲染，退出/登出时销毁资源。返回键优先关 Sheet、退出全屏、退详情/上传流程，再回主页；主页再返回由系统处理退出。拦截有未提交草稿/传输的离开操作，不能默默丢失数据。

## 4. 页面规格

### 登录/注册

```text
Phone                     Pad
┌─────────────────┐       ┌────────────────────────────────────┐
│           中/EN │       │                              中/EN │
│                 │       │          [透明 logo_nw]             │
│ [透明 logo_nw]  │       │          欢迎使用 XJICloud           │
│ 欢迎使用        │       │       ┌────────────────────┐       │
│ [用户名       ] │       │       │ 用户名             │       │
│ [密码      眼睛]│       │       │ 密码            眼睛│       │
│ [验证码] [图像] │       │       │ 验证码/登录按钮     │       │
│ [    登录     ] │       │       └────────────────────┘       │
│ 没有账号？注册  │       │                                    │
└─────────────────┘       └────────────────────────────────────┘
```

- 白底；复用 `apps/web2/public/logo_nw.png` 的透明原图，不加白色色块/滤镜。实施时复制到 Flutter assets，不跨目录运行时读取。Logo 约 88–104dp，不占满上半屏。
- SafeArea + 可滚动表单，Phone 最大宽 420dp，Pad 也居中保持此宽；键盘弹起缩小顶部留白，焦点字段和提交按钮可滚动到可见位置。
- 56dp 高输入，10dp 圆角、浅描边；标签不只靠 placeholder，焦点 accent 边框，错误下方文字；密码可见开关、自动填充、下一项/完成动作。
- 登录字段 username/password；注册增加可选 displayName、确认密码（仅客户端校验）、必填验证码。用户名 3–64、密码 6–128、显示名最多 128，后端为最终校验依据。
- 登录按 need-captcha 结果展示验证码；注册始终展示；验证码可刷新，加载失败有明确重试。失败后刷新已消耗的验证码；不长期存密码。
- 注册成功切回登录并提示（与当前 Web UI 一致），不能误认为注册响应不存在 token；首次登录成功落主页，受保护深链只允许站内已定义路由。
- 提交中按钮防连点；输入错误保持可修正字段，禁止全屏错误页。切登录/注册采用高度/淡入动画；不强制移植桌面的跟随装饰角色。

### 主页

顶部问候和当前工程摘要；最近最多 5 个工程，点击切 workspace 后进入详情；无工程时显示“创建第一个工程”和导入说明。快捷动作只有创建工程、上传训练、打开本机模型。当前工程训练摘要来自实际 jobs，不显示跨工程伪统计、随机模型缩略图、占位搜索框。

### 工程管理

Phone：卡片列表 → 工程详情；卡片包含名称、描述、创建时间、当前工程状态和溢出菜单。详情分“模型 / 训练任务”区块，提供改名/描述、选择为当前、确认删除。Pad 宽窗左工程列表右详情，列表默认不误选其他账号历史工程。

模型行展示文件名、PLY/SPZ、大小、更新时间，操作为查看、下载、删除；上传由中央入口或详情内同一用例进入。任务行展示真实状态、阶段、百分比、失败原因；进行中可取消，终态可删除。危险动作确认文案写清工程名/模型名与后果，不靠手势滑动直接删除。

### 上传与训练

Phone 全页三步：①目标工程与类型 ②文件选择/图片清单 ③校验汇总与上传。Pad 显示步骤栏、左侧选择右侧汇总，但使用同一用例。图片支持系统多选与目录选择；仅 JPG/JPEG/PNG/WebP，不把 HEIC、视频、ZIP 静默当图片。

清单显示数量、总大小、不支持项和排序规则；空选择/无权限/空间不足可修复。先用户确认清单再创建服务端 job。显示“准备文件→上传→提交训练”，总进度按字节而非图片个数；训练状态另行显示，上传 100% 不代表训练完成。

切后台显示本地暂停状态，不把服务端 UPLOADING 改成 CANCELLED；回前台提供继续。签名过期/进程退出无法恢复时解释需要重新提交；能复用的模型分片继续已收字节。取消上传与取消服务端训练用不同确认文案。断网、complete 结果不确定时先查询状态。

### 模型查看

空态提供“打开本机 PLY/SPZ”和“选择当前工程模型”，没有工程也可打开本机。云模型列表来自指定工程，没有全站模型搜索。云下载→本地文件→SDK 解码→GPU 上传→首帧就绪均可见，支持取消；候选失败保留旧场景。

普通模式保留底栏；“全屏”进入沉浸画布并隐藏底栏，退出手柄/返回恢复。Phone 顶部显示模型名和关闭，底部放浏览模式、适配、重置，缩放/Y 翻转进入工具 Sheet；Pad 可浮动工具栏，但仍单画布。不在 Viewer 放上传/删除/编辑。

固定模式：单指 orbit、双指平移/捏合缩放；自由模式：单指 look、专用移动摇杆/上下按钮，工具栏不能同时触发画布手势。dx/dy 从 Flutter 逻辑像素变为 Surface 实际像素；pinch 连续变化映射 dolly，节流合并到帧，不逐点解码或传整模型。

截图与 Web 行为对齐但**不是首个渲染闭环硬门槛**：SDK 无截图 API，须另验 PixelCopy 对 SurfaceView 是否正确包含图像、保存/分享权限及隐私。验证通过才开放 PNG 按钮，不显示永远失败的占位入口。

### 我的

展示当前 session 中的 displayName/username；语言切换、账号隔离缓存大小/逐项删除/清空、离线帮助、关于与 SDK 许可证、退出。没有用户资料修改/密码修改接口，不新增这些表单；退出后受保护页面不可返回。清缓存不能删除 viewer 正在使用的文件或上传源文件。

## 5. 状态与无障碍

每页都定义 loading/empty/content/error；错误保留已有可用内容，网络重试不重复提交 mutation。Phone 使用 Sheet；Pad 宽窗表单可用最大宽 480dp Dialog。加载按钮有可读标签，错误用 live-region/语义提示，选中 Tab 有 selected 语义；Logo 不重复朗读装饰文字。检查 TalkBack、200% 字号、亮/暗画布对比、焦点顺序、系统返回/预测返回。
