## Code Review

对最终产品 diff 做第二次自我审查，顺序为正确性、鉴权/隔离、生命周期与取消、架构回归、测试缺口；没有用实现清单代替缺陷检查。二次审查发现并追加修复：

1. dirty 查询期间仍可启动保存：`switching` 改为响应式状态，保存/版本入口参与互斥。
2. SSE 主动取消时 pending reader 未及时释放：主动 cancel，迟到 response 同样取消。
3. 等待层 backdrop 会意外取消上传：仅显式取消按钮或 Escape 执行取消。
4. mutation 后旧缓存/网络读仍可能返回：per-model revision 拒绝先前读取结果。
5. workspace reset 到页面卸载存在窗口：上传组件直接订阅 workspace 并立即取消 owner。
6. File.arrayBuffer 永久 pending 时无法退出：读取等待也响应 abort 和截止。
7. 历史下载与版本列表缺少完整 owner 检查：传 signal 并核对 modelId/disposed。
8. 上传 session 创建期间取消返回错误码不准确：统一为明确的取消结果。
9. 损坏 cache index 可能被当作空索引覆盖：仅 NotFound 视为空，损坏/字段非法直接报错并走仓库降级。

上述追加修复均已纳入最终测试；本次范围内未发现仍未解决的 High/Critical。现有未知风险集中在上表明确保留的外部验收缺口；本审查不代表第三方引擎内部、后端或部署的全面安全审计。
